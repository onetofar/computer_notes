> 写给**0 前端基础、但有老式 CSS/JS/H5 经验、且懂 C++** 的人。目标只有一个：**能读懂项目里的 Vue3 前端源码**（尤其网站制作的 3 篇前端文档）。不追求会写，只追求能读。

## 为什么需要这套笔记

你在读 [[1-MOC 全链路总览-索引]] 时，会碰到三篇前端文档：
- [[前端3D场景-GameRoom.vue]]
- [[前端游戏状态-game.js]]
- [[前端WS客户端-ws.js]]

它们都是 **Vue3 生态** 的代码。Vue3 和"老式 JS"差了一个时代：模板语法、响应式、单文件组件、Pinia 状态管理、路由守卫……如果不补这几块认知，前端层永远是黑盒。

```

   │
   ▼
[0] 老式JS与DOM前置认知基础                ← 已遗忘的 getElementById/addEventListener 等
   ▼
[2] 从老式JS到Vue3：为什么需要框架        ← 建立动机，认识"声明式 vs 命令式"

   ▼

   ▼

   ▼
[6] Pinia 状态管理                        ← 类比 C++ 全局单例

```

## 每一篇的最小闭环

每篇都按同样的结构组织，**每篇结束你都能带走一个"能读代码"的认知**：

```
1. 一句话定义（是什么）
2. C++ / 老式JS 类比（你已会的 → 新概念）
3. 最小代码示例（不超 30 行）
4. 真实源码对照（项目里哪里用到了）
5. 自测问题（1-2 个，答不出回头看）
```

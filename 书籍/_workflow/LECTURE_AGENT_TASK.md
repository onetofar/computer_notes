## 1. 你要做的事

- 输入：原文稿 `/mnt/kb/markdown/书籍/教材原文/<书名>/<原文稿文件名>.md`
- 输出：`/mnt/kb/markdown/书籍/教材讲义/<书名>/<原文稿 basename 去数字前缀>（讲义）.md`
- **一篇原文稿 = 一篇讲义。** 只写派给你的那一篇。

### 动手第一步：列真实标题编号

```bash
grep -n "^#\{1,5\} " "/mnt/kb/markdown/书籍/教材原文/<书名>/<原文稿文件名>.md"
```

| 书 | §-定位器形式 |
|---|---|
| CiA 正文 | `§5.1`、`§5.1.2`（原文稿里是 `#### 5.1. …` 与 `##### 5.1.2. …`） |
| CiA 附录A | `§A.1`、`§A.4.2`（**字母编号**） |
| CiA 附录B/C/D | `§附录 B`（原文稿里是 `# Appendix B. …`，**只有一级标题**） |
| SP | `§6.2.1`（原文稿里是 `#### 6.1 …`、`##### 6.2.1 …`） |
| SP 附录 | `§附录 A`（原文稿里是 `# Appendix A： …`，**只有一级标题**） |

- **原文里没有的编号一律不许造。**
- **讲义自己的编号不带 §**（`### 8.0`、`### 1.1` 都不带）。

### 动手第二步：抽金句

- **8–18 条**，每条 = **原书原句（加粗，逐字照抄英文原文）** + 一句中文点评。
- **逐字是硬要求。** 引文里不能有 `<`、`>` 这种会被 Markdown 当标签吃掉的字符
  （`<chrono>`、`std::atomic<int>` 之类）—— 挑不含尖括号的句子。
- 引文**末尾标点必须与原文一致**；引到句子中间就留逗号，别替原文句号化。
- ⚠️ 脚注号会插在句中（epub 副作用），取脚注号之前的片段，别「修顺」。

## 2. 校验（落盘之后才做）

```bash
cd /tmp/ostep && python3 -I verify_quotes.py 2>&1 | head -20
```

- 你的那篇若出现在「对不上」里 ⇒ 逐字被你改过了，**改回原文**。
- 全局计数里的「对不上」必须是 **0**。若不是 0 且不是你的篇，**别改别人的**，只报告。

写完用 Read 工具**重读一遍**（CIFS 缓存会骗你），确认无乱码、无半截句子、frontmatter 闭合。

CSAPP(深入理解计算机系统)系列笔记,这是自底向上的基础,以程序员的角度去看待计算机的硬件
这是被誉为程序员圣经的书籍,因为它统筹了大学学的零散的一切知识点,包括计算机组成原理,操作系统,数据结构,计算机网络等
一个程序员的最高境界就是于计算机的拉普拉斯妖的存在,要知道你写的每一行代码在底层如何流转,怎么进入CPU又怎么被消耗变化,最后产生系统级的响应

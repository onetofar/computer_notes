# TCP头部 [TCP头部.md](3-1 TCP头部.md) 

```asc
┌───────────────────────────────┬───────────────────────────────┐
│ 源端口(16位,2字节)            │ 目的端口(16位,2字节)          │
├───────────────────────────────────────────────────────────────┤
│                        序列号(32位,4字节)                      │
├───────────────────────────────────────────────────────────────┤
│                        确认号(32位,4字节)                      │
├───────┬───────┬──────────┬───────────────────────────────┤
│头长度4│保留4  │标志位6   │ 窗口大小(16位,2字节)          │
├───────────────────────────────┬───────────────────────────────┤
│ TCP校验和(16位,2字节)         │ 紧急指针(16位,2字节)          │
├───────────────────────────────────────────────────────────────┤
│                      选项(可变长)                             │
└───────────────────────────────────────────────────────────────┘
```

标志位6位:

CWR：拥塞窗口缩减（发送方主动降低发送速率），详见第 16 章；

ECE：显式拥塞通知回显（发送方收到拥塞通知），详见第 16 章；

URG：紧急标志（紧急指针字段生效，极少使用），详见第 15 章；

ACK：确认标志（确认号字段生效；连接建立后该标志位始终置 1），详见第 13、15 章；

PSH：推送标志（接收方需立即将数据交付给应用层，功能实现不完善、极少使用），详见第 15 章；

RST：复位标志（强制断开连接，通常用于异常场景），详见第 13 章；

SYN：同步标志（同步序列号，用于发起连接），详见第 13 章；

FIN：结束标志（报文发送方完成数据发送），详见第 13 章。

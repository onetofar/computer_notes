## 二、同步语义

快照、插值、外推、延迟补偿。**玩家感知的延迟不是 RTT，是 `½RTT + 插值周期`**。
这一支决定所有同步参数的取值下限。

- [[第5章 对象复制|全量快照与增量]] — 全量天然幂等：每包自足、丢包下一包自然修复、接收端零簿记；增量的全部复杂度来自"不能假设接收方基于上一包"。**全量是"小世界"的零成本最优解，增量是规模逼出来的交换**
- [[第8章 改进的延迟处理|客户端插值与预测]] — 感知延迟 = `½RTT + IP`，`IP = PP` 是被两侧约束夹死的唯一解；RTT **只能用自己发的输入时间戳回环算**；远程玩家航位推测+分级纠正、本地玩家移动重放（重放未确认输入）、动作反馈用 tell 技巧本地先行
- [[第8章 改进的延迟处理|服务器端回退]] — 命中判定回退到玩家扣扳机那一刻看见的世界。四个要件：远程插值（可精确重建视野）/本地预测重放/包内带两帧 ID+插值百分比/服务器存最近几帧位姿——只需位置历史查询，不必完整时间回滚；代价记在被击中者账上
- [[第7章 延迟、抖动和可靠性|复制可靠性]] — 丢包后重批**命令**而非重发旧字节：`mNetworkIdToReplicationCommand` 账本 + InFlightPacket 记录「这个包写了什么」，失败回调按对象**最新状态**重新入账（Tribes ghost 式）。值语义状态免回滚；一次性事件不能走这套。状态走快照、事件才需要可靠层
- [[第1章 网络游戏概述|四类数据与双原型]] — 两大原型由「相关集合的形状」决定：单元多玩家少→锁步同步命令，玩家多相关少→状态同步。Tribes 四类数据（非保障/保障/最近状态/最快保障）= 可靠性按数据类型配置，不是传输层一个开关；帝国时代 200ms 轮 + 两轮宽限 = 恒定 600ms 输入延迟换确定性
- [[第6章 网络拓扑和游戏案例|权威服务器与客户端代理]] — 实现骨架三件套：代码三层分叉（共享库/Server/Client）、HELO/WLCM 幂等状态机（重传免费）、ClientProxy 三重身份（输入缓冲/每客户端复制账本/延迟补偿锚点）。上行只有 Move 流（InputState+timestamp+Δt），下行只有 STAT
- [[第6章 网络拓扑和游戏案例|P2P 锁步实现]] — 命令在第 x 轮产生第 x+2 轮执行；`mTurnData[轮][玩家]` 缺口检测；确定性=同种子同调用序（rand() 出局用 MT19937）+ 每轮 PRNG 心跳与全局 CRC（按 ID 升序）双校验；主对等体只管地址与发 ID，宕机无碍
- [[第11章 真实世界的引擎|商业引擎网络]] — UE4/Unity 是第 1–10 章机制的工业封装：三种角色（authority/simulated/autonomous proxy）、owner-only RPC（归属验证引擎化）、UNET QoS 四档=四类数据成品化、SyncVar 整包陷阱=自动化与带宽精度的固有权衡；自研协议照镜子学「把纪律灌进 API 形状」

## 四、安全与运营

反作弊、平台服务、部署运维——**服务器是自己的**（专用/云托管）之后才成立的三件事。

- [[第10章 安全性|网络安全四层]] — 传输保密→输入验证→软件作弊检测→服务器防护。主机嗅探防不住 ⇒ C/S 真护城河=限知广播（服务器别发，而不是加密）；非法输入**拒绝但不踢**（区分恶意与乱序无辜）；常时比较（XOR 归约）防时序攻击——协议哈希校验就是这个位置

- [[第13章 云托管专用服务器|云托管专用服务器]] — 四层金字塔（实例⊂进程⊂VM⊂硬件）+ LSPM/VMM 两级同构心跳（20s/10s/5s 三参数）；**每局结束重启进程**把泄漏与状态污染封顶在单局内

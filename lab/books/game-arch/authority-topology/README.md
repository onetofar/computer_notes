# 对照讨论：谁说了算（客户端权威 / 服务器权威 / 监听服务器 / 同步频率）

> **问题**：同一个世界里，**真相放在哪台机器上**？
> 权威模型不是口号，是一条可执行判据；而同步频率是权威模型的带宽账单。

## 对照表

| 文件 | 差异点 | 预期输出 |
| --- | --- | --- |
| `01-client-authoritative.cpp` | 客户端自己算位置并上报 | 同一只猫出现 `60 与 99999 两个位置 -> 两台显示器开始打架`；作弊上报服务器照单全收 |
| `02-server-authoritative.cpp` | 客户端只发输入，服务器裁决 | 两客户端收敛到同一 `x=20`；伪造位置无效；感知延迟 = 半个 RTT |
| `03-topology-and-listener-server.cpp` | C/S 星形 vs P2P 全互联；监听服务器 | 8 人房 `C/S 星形 8 条, P2P 全互联 28 条`；监听服务器三个代价 |
| `04-sync-rate-tradeoff.cpp` | 服务器同步频率 vs 客户端帧率 | 15 包/秒 → `每个位置要画 4.0 帧`（幻灯片）；60 包/秒 → 带宽 `4.0 倍` |

横向看：01 与 02 是同一件事的两种答法——
**客户端不能自己决定结果**；03 是这笔权威模型的账（连接数、带宽、延迟）；
04 是它的账单（带宽换幻灯片）。

## 教材原话（逐字引文）

> - **客户端-服务器（C/S）**：选一个人当裁判，其他所有人都是**显示器**。你的电脑只负责两件事：告诉服务器"我按了前进键"，然后把服务器告诉你的一切画出来。**真相只有一份，在服务器手里。**
> - **对等网络（P2P）**：没有裁判。每个人电脑里都跑着**完整的世界模拟**，网络上只传递"我打算做什么"（命令），不传"世界是什么样"（状态）。**真相有 N 份，全靠大家算得一模一样。**

> P2P 的连接数是 **n(n−1)/2**——人数翻倍，连接数大约翻 4 倍。

> - C/S：服务器的带宽**随人数线性涨**（8 个人的进出流量全过它的手），但**每个客户端恒定**（只连服务器一条线）——这就是它**可扩展**的原因：加人只苦服务器，不苦玩家；
> - P2P：把"线性涨"**摊到每个人头上**——8 人房间里，你的上传 = 把你的动作发给其他 7 个人。人人平等地苦。

> 省钱的办法：**让某个玩家的电脑兼任服务器**（监听服务器）。代价三个，一个比一个疼：权威数据在玩家手里（**开挂的是服务器本身**）；他一断线全场崩；他退出还得"迁移主机"。原文特别纠正一个误称：监听服务器**不是**对等网络——它仍然有一台服务器，只是恰巧被玩家托管了。

> 判据就一句话：**客户端不能自己决定结果**。代价是每个动作都要等一个来回（RTT），收益是所有人共享同一份真相。

> 2. **幻灯片**——客户端 60fps 渲染，但带宽只够服务器每秒发 15 次状态，同一个位置要连画 4 帧。**花钱买的高级 GPU，被网络限成了 15fps**；

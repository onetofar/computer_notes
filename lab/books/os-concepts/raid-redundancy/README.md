# RAID: 条带化 vs 镜像 vs 奇偶校验

对照问题: 同样 5 块盘, 三种冗余方案各花多少容量、写多少物理 I/O、坏一块还能不能救回来?

| 文件 | 差异点 | 预期输出 |
| --- | --- | --- |
| [01-raid0-stripe.c](./01-raid0-stripe.c) | 条带化, **无冗余**: 盘号 = A % N, 偏移 = A / N | `RAID-0: 容量=10 块 物理写次数=10 可恢复=8/10 丢失=2 (冗余=0)` |
| [02-raid1-mirror.c](./02-raid1-mirror.c) | 镜像, 每块写两份 | `RAID-1: 容量=2 块 物理写次数=4 可恢复=2/2 丢失=0 (冗余=1)` |
| [03-raid4-parity.c](./03-raid4-parity.c) | 4 数据盘 + 1 校验盘, 异或校验, 小写走减法奇偶校验 | `RAID-4: 容量=4 块 全条带写=5 次 小写=4 次 I/O 恢复校验=通过 (冗余=1)` |

三个文件都是**纯逻辑模拟**: 没有真实磁盘, 只算"逻辑块 → 物理盘"的映射、物理 I/O 次数, 以及"某块盘整盘死亡(fail-stop)"之后还能不能恢复。

⚠️ **关于"校验和 vs 奇偶校验"**: 讲义第 38 章里**没有** checksum 这种冗余方案——它讲的是 RAID-0/1/4/5。所以这组对照取讲义真实存在的三档: **镜像(RAID-1) vs 奇偶校验(RAID-4)**, 顺带拿 RAID-0 当"没有冗余"的基准线。

## 教材原话

> **映射问题**（给定逻辑块号 A，怎么算出物理位置）——两个整数运算就够：
>
> ```
> 磁盘号 = A % N
> 块偏移 = A / N      （整数除法）
> ```


—— 《操作系统导论》第 38 章讲义 §38.4「RAID-0：条带化」([[38-第38章 廉价冗余磁盘阵列（RAID）]])

> **异或（XOR）**：偶数个 1 ⇒ 结果 0；奇数个 1 ⇒ 结果 1。不变式是**每行 1 的个数必须是偶数**。恢复时：某列丢了，就把同行其他值（含校验位）再 XOR 一次，缺的那一步是唯一的。块级 XOR 同理——逐位算，结果放进校验块的对应位置。


—— 《操作系统导论》第 38 章讲义 §38.6「RAID-4：用奇偶校验省空间」

> **减法奇偶校验**只读旧数据 + 旧校验，一行公式出结果：
>
> ```
> P_new = (C_old ⊕ C_new) ⊕ P_old
> ```


—— 《操作系统导论》第 38 章讲义 §38.6

> 减法把每次写降到 **4 个物理 I/O**（2 读 + 2 写）。


—— 《操作系统导论》第 38 章讲义 §38.6

> **顺序写：全条带写入（full-stripe write）**——一次写满一个条带（块 0,1,2,3 + P0），5 块并行，是 RAID-4 最有效的写方式。顺序读与顺序写都是 (N−1)·S，随机读是 (N−1)·R。


—— 《操作系统导论》第 38 章讲义 §38.6

> **写**：**必须写两个副本**，两个可以并行发起。


—— 《操作系统导论》第 38 章讲义 §38.5「RAID-1：镜像——最直白的冗余」

> **RAID-0 的三把尺子**：容量 N（顶级）；可靠性 0（最烂：任何一块盘坏，它上面的数据全没）；单请求延迟 ≈ 单盘延迟 T，稳态吞吐 = N·S（顺序）、N·R（随机）。


—— 《操作系统导论》第 38 章讲义 §38.4

## 讨论点

1. 容量账: RAID-0 用满 5 块盘, RAID-1 只剩一半, RAID-4 少一块——讲义"没有免费的 RAID"说的就是这一栏。
2. 写放大账: RAID-0 每逻辑块 1 次物理写; RAID-1 写两份; RAID-4 全条带写 5 次, 但**小写**要 4 个 I/O(2 读 + 2 写)——这就是讲义里 RAID-5"随机小写 N/4·R"的来源。
3. `03` 里磁盘2 坏掉后, 恢复出来的字节正好是原值(08 09 0a 0b), 并且"恢复校验=通过"——异或的自校正性质在代码里是能验证的, 不是背结论。
4. RAID-1 与 RAID-4 的差别不是"谁更可靠"(都只容 1 块), 而是**用容量换可靠性**: 镜像简单但费盘, 奇偶省盘但小写贵。
